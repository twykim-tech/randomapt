# 🏢 RANDOM.APT SEOUL — 인스타그램형 서울시 랜덤 아파트 피드 & 임장 룰렛 탐색기

이전에 제작한 `RANDOM.ARCHI`의 인스타그램형 UI를 기반으로, **서울특별시 7대 권역(25개 자치구) 핵심 아파트 단지**를 무작위로 탐색하고, 실거래·학군·역세권 스펙 비교 및 **랜덤 임장지 룰렛 뽑기**를 즐길 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능
- **서울 7대 권역 인스타그램 스토리 바 필터**: `강남·서초·송파(강남3구)`, `용산·성동·마포(마용성)`, `영등포·양천·강서(여의도·목동·마곡)`, `강동·광진·동작`, `종로·중구·서대문`, `노원·성북·동대문`, `은평·관악·구로` 권역별 필터링
- **인스타그램 아파트 피드 & 핵심 스펙 그리드**:
  - 단지별 전용 84㎡ 매매/전세 시세 참고가, 총 세대수·동수·최고층, 용적률·세대당 주차대수, 최인접 지하철역, 배정 초·중·고 학군 정보 한눈에 표시
  - 원클릭 **네이버 부동산 매물·시세**, **네이버 지도**, **카카오맵 로드뷰**, **호갱노노 실거래** 연동 버튼 제공
- **서울 랜덤 아파트 룰렛 뽑기 (`단축키 S`)**:
  - 서울 전체 또는 원하는 권역을 선택해 오늘 탐험하거나 임장할 아파트를 무작위로 추천
- **랜덤 피드 셔플 (`단축키 R`) & 정렬 전환 (`랜덤순 / 세대수순 / 신축순`)**
- **바둑판 탐색 뷰 (`단축키 G`)**: 3열 그리드 뷰로 한눈에 서울 주요 단지 사진과 시세 탐색
- **부동산 필수 플랫폼 디렉토리 & 실시간 서울 아파트 뉴스 브리핑**: 호갱노노, 네이버 부동산, 아실, 국토부 실거래가 공개시스템, 서울부동산정보광장, 정비사업 정보몽땅, 청약홈 등 10대 필수 사이트 수록
- **관심 단지 보드(북마크) / 하트 / 내 임장 노트**: 브라우저 로컬 스토리지 기반 나만의 임장 메모 및 관심 단지 관리

## 🚀 로컬 실행 방법
```bash
node server.js
# 또는 Windows에서 start.bat 더블클릭
```
브라우저에서 `http://localhost:3800` 접속
